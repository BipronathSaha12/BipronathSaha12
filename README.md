## 👨‍💻 Executive Summary

I am a **Senior Full-Stack & DevOps Engineer** passionate about architecting high-availability cloud platforms, resilient backend services, and interactive web applications. Bridging software engineering with operations, I design end-to-end systems built for scalability, security, and continuous delivery.

### 💡 Core Engineering Focus
- ☁️ **Cloud Infrastructure & Orchestration:** Designing containerized workflows with Docker & Kubernetes, managing AWS cloud environments, and establishing zero-downtime CI/CD automation.
- ⚙️ **High-Performance Backends:** Architecting RESTful & GraphQL APIs using Python (Django REST Framework) and Node.js backed by PostgreSQL and Redis.
- 🌐 **Modern Frontend Development:** Building dynamic, accessible UI interfaces using JavaScript (ES6+), React, and Tailwind CSS.
- 📡 **IoT & Edge Telemetry Pipelines:** Developing real-time data ingestion pipelines connecting ESP32 hardware & sensors to backend streaming platforms.
- 🛡️ **Observability & Reliability Engineering:** Implementing end-to-end logging, monitoring, and automated failovers for 99.9%+ uptime guarantees.
